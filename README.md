# 源石动力炉与燃料缓冲仓

**Astra × Blender｜从设定集插画到 3D 场景的一次尝试**

灵感来源于《明日方舟》官方世界观设定集《大地巡旅》第 7 页的「源石动力炉与燃料缓冲仓」示意图。

最近听说 Astra 挺厉害，于是我就把这张图发给 Astra，让它通过 BlenderMCP 在 Blender 里建了这个场景。没想到建得还不错，于是就传上来分享一下。

这里放出了 Blender 工程和两张渲染图，记录这次从参考图到 3D 场景的尝试。

## 场景总览

![场景总览](overview.png)

## 场景里有什么

- 中央动力炉与两个格栅燃料缓冲仓。
- 架空管网、阀门、仪表及软管。
- 剖面厂房钢架、检修平台、楼梯与爬梯。
- 六个命名集合，保留可编辑部件、材质、灯光及两台相机。
- 工程内嵌参考图与建模脚本。

## 关于还原

这是基于参考图制作的非官方场景练习。原图没有提供尺寸，模型按视觉比例估算，并对部分结构、管线和材质做了补充，并不是原图的严格复刻或工程施工模型。

《明日方舟》相关设定及原始参考图的权利归原权利人所有。
