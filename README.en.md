# Originium Power Furnace & Fuel Buffer Chambers

[简体中文](README.md) | **English**

**Astra × Blender | An experiment in turning a worldbuilding illustration into a 3D scene**

Inspired by the diagram of the Originium power furnace and fuel buffer chambers on page 7 of 《大地巡旅》, the official Arknights worldbuilding book.

I'd heard Astra was pretty impressive, so I sent it the illustration and asked it to build this scene in Blender through BlenderMCP. It turned out better than I expected, so I decided to upload it and share it here.

This repository contains the Blender project and two rendered images, documenting the experiment of turning a reference illustration into a 3D scene.

## Scene Overview

![Scene overview](overview.png)

## What's in the Scene

- A central power furnace and two fuel buffer chambers with metal grilles.
- Overhead pipework, valves, gauges, and flexible hoses.
- A cutaway industrial hall with a steel frame, maintenance platform, stairs, and a ladder.
- Six named collections containing editable components, materials, lights, and two cameras.
- The reference image and modeling scripts embedded in the Blender project.

## About the Reconstruction

This is an unofficial scene study based on the reference illustration. The original image does not specify dimensions, so the model uses estimated visual proportions, with additional interpretation of some structures, pipework, and materials. It is not an exact replica or an engineering model.

The Arknights setting and original reference illustration belong to their respective rights holders.
